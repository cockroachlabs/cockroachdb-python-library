def build_staleness( staleness: str = 'follower_read_timestamp()', *, hours_ago: int = 0, minutes_ago: int = 0, seconds_ago: int = 0) -> str: 
12def build_staleness(
13    staleness: str = "follower_read_timestamp()",
14    *,
15    hours_ago: int = 0,
16    minutes_ago: int = 0,
17    seconds_ago: int = 0,
18) -> str:
19    """Build an ``AS OF SYSTEM TIME`` expression.
20
21    Additive staleness: ``hours_ago``/``minutes_ago``/``seconds_ago`` add up
22    and, when their total is positive, compose to ``'-Ns'`` which takes
23    precedence over *staleness*. When no parts are set, *staleness* is returned
24    unchanged (default ``follower_read_timestamp()``).
25
26    This is the single source of truth for the fail-fast rule: a negative part
27    raises immediately rather than silently falling back to a current read.
28
29    Args:
30        staleness: Fallback AS OF SYSTEM TIME expression used when no
31            additive parts are set.
32        hours_ago: Whole hours of staleness to add. Must be >= 0.
33        minutes_ago: Whole minutes of staleness to add. Must be >= 0.
34        seconds_ago: Whole seconds of staleness to add. Must be >= 0.
35
36    Returns:
37        Either ``'-Ns'`` (composed from the additive parts) or *staleness*.
38
39    Raises:
40        ValueError: if any additive part is negative.
41    """
42    for name, value in (
43        ("hours_ago", hours_ago),
44        ("minutes_ago", minutes_ago),
45        ("seconds_ago", seconds_ago),
46    ):
47        if value < 0:
48            raise ValueError(f"{name} must be >= 0, got {value}")
49
50    total_seconds = hours_ago * 3600 + minutes_ago * 60 + seconds_ago
51    if total_seconds > 0:
52        return f"'-{total_seconds}s'"
53    return staleness

Build an AS OF SYSTEM TIME expression.

Additive staleness: hours_ago/minutes_ago/seconds_ago add up and, when their total is positive, compose to '-Ns' which takes precedence over staleness. When no parts are set, staleness is returned unchanged (default follower_read_timestamp()).

This is the single source of truth for the fail-fast rule: a negative part raises immediately rather than silently falling back to a current read.

Args: staleness: Fallback AS OF SYSTEM TIME expression used when no additive parts are set. hours_ago: Whole hours of staleness to add. Must be >= 0. minutes_ago: Whole minutes of staleness to add. Must be >= 0. seconds_ago: Whole seconds of staleness to add. Must be >= 0.

Returns: Either '-Ns' (composed from the additive parts) or staleness.

Raises: ValueError: if any additive part is negative.

 39
 40    Supports both sync and async functions. Each retry executes the
 41    entire decorated function, creating a fresh transaction as required
 42    by CockroachDB's retry protocol.
 43

 45        max_retries: Maximum number of retry attempts.
 46        base_delay: Initial delay in seconds before first retry.
 47        max_delay: Maximum delay cap in seconds.
 48        multiplier: Exponential backoff multiplier.
 49        jitter_factor: Random jitter as fraction of delay (0.0 to 1.0).
 50        isolation: Transaction isolation level.
 51        on_retry: Optional callback invoked on each retry with (attempt, error).
 52    """
 53

 55        if inspect.iscoroutinefunction(fn):
 56
 57            @functools.wraps(fn)
 58            async def async_wrapper(*args: P.args, **kwargs: P.kwargs) -> T:
 59                last_err: Exception | None = None
 60                for attempt in range(max_retries + 1):
 61                    try:
 62                        return await fn(*args, **kwargs)  # type: ignore[no-any-return]
 63                    except Exception as e:
 64                        if not is_retryable_error(e):
 65                            raise
 66                        last_err = e
 67                        if attempt < max_retries:
 68                            if on_retry:
 69                                on_retry(attempt + 1, e)
 70                            delay = _calc_delay(
 71                                attempt, base_delay, max_delay, multiplier, jitter_factor
 72                            )
 73                            await asyncio.sleep(delay)
 74                raise CockroachDBRetryExhausted(max_retries, last_err) from last_err

 78            return async_wrapper  # type: ignore[return-value]
 79
 80        @functools.wraps(fn)
 81        def sync_wrapper(*args: P.args, **kwargs: P.kwargs) -> T:
 82            last_err: Exception | None = None
 83            for attempt in range(max_retries + 1):
